# 山ノ製作所 採用LP

20〜30代向けの建設・施工会社の採用LPポートフォリオです。

## 構成
- `index.html` — SEO/AEOを意識したページ構造・JSON-LD
- `css/reset.css` — リセットCSS
- `css/style.css` — レスポンシブ・アニメーション・デザイン
- `js/main.js` — スクロールプログレス、リビール、数字カウント
- `php/contact.php` — 採用問い合わせフォームのサンプル

## 画像について
現在の人物写真はポートフォリオ用の仮素材です。実案件公開時は、利用許諾を確認した素材または山ノ製作所の実写真へ差し替えてください。

## PHPについて
GitHub PagesはPHPを実行できません。GitHubでポートフォリオを公開する場合は、LPの静的部分をGitHub Pagesで表示し、`php/contact.php`はPHP対応サーバーへ配置してください。

## 本番前に差し替える情報
- 実際の給与
- 勤務時間
- 休日・休暇
- 勤務地の市区町村・現場エリア
- 電話番号
- メールアドレス
- 応募フォームURL
- LINE公式アカウントURL
- 実際の社員・現場写真


## 人物ビジュアル
施工スタッフ・営業・事務の3職種に人物写真を設定しています。画像URLは `index.html` の各 `img` / hero背景から差し替え可能です。公開時は利用規約を確認した実素材へ変更してください。
